Copilot CLI をインストールし、会話を試したので、次はプロジェクトに初めて変更を加えます。小さな変更から始めましょう。ゲームのデータにはすでに星評価がありますが、ホームページのゲームカードには表示されていません。エージェントに評価を表示するよう依頼し、変更を確認して、最初のプルリクエストとしてマージします。

このレッスンでは、次の操作を行います。

- 機能ブランチで、目的を絞った Copilot との会話を始めます。
- エージェントにプロジェクトへの小さな変更を依頼します。
- `/diff` で変更を確認します。
- 転送したブラウザーでアプリを実行し、変更を確認します。
- 最初のプルリクエストを作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価があり、ゲーム詳細ページにはすでに表示されています。一方、ホームページのゲームカードに表示されるのは、タイトル、カテゴリ、パブリッシャー、説明だけです。練習として、エージェントに既存の評価を各カードに表示してもらいます。小さく完結した変更なので、最初のセッションにぴったりです。

## 会話の構成

**会話**とは、タスクについて Copilot CLI と作業する場です。Copilot app とは異なり、通常の CLI 会話では専用の worktree を作らず、ターミナルで現在チェックアウトしているリポジトリと Git ブランチを使います。保存した会話を後で再開できますが、ファイルとブランチはディスク上の通常の Git 状態のままです。

会話には、プロンプトとエージェントの応答、ファイルの調査や編集などエージェントが使ったツール、`/diff` で確認できる変更の3つが表示されます。

## 会話を始めて変更を依頼する

機能の実装を始めるため、新しい会話を始めましょう。

1. Codespace に戻ります。
2. まだターミナルを開いていない場合は、<kbd>Control</kbd>+<kbd>`</kbd> (Mac) または <kbd>Ctrl</kbd>+<kbd>`</kbd> (Windows/Linux) を押します。
3. まだ起動していない場合は、次のコマンドで Copilot を起動します。

   ```bash
   copilot --yolo
   ```

4. スラッシュコマンド `/new` を実行し、<kbd>Enter</kbd> を押して新しいセッションを開始します。
5. 次のプロンプトで変更を依頼します。

   ```plaintext
   ゲーム一覧ページのゲームカードに、各ゲームの星評価を5段階で表示してください。評価が null の場合は「評価はまだありません」と表示してください。カードのレイアウトはそのままにし、テストを追加して、関連するチェックを実行してください。
   ```

Copilot はプロジェクトを調べ、ゲーム詳細の表示に使うファイルを探して、必要なコードを作成します。Copilot CLI を使って新機能を追加できました。

## 差分を確認する

AI が生成した変更は、小さなものでもマージ前に確認しましょう。Copilot CLI で変更を見てみます。

1. `/diff` を実行し、変更されたすべてのファイルを確認します。
2. 評価がある場合は数値が、`starRating` が `null` の場合は `No rating yet` がゲームカードに表示されることを確認します。
3. テストで両方の状態がカバーされていることを確認します。
4. Copilot が実行したチェックの結果を確認し、失敗があれば修正を依頼します。
5. 確認が終わったら、<kbd>Esc</kbd> を押して差分画面を閉じます。

> [!NOTE]
> Copilot を含む生成 AI ツールは決定論的ではなく、確率に基づいて結果を生成します。そのため、実際のコードはここに示すものと異なる場合があります。特定の実装を期待するのではなく、動作を確認してください。

## 変更を確認する

コードを読んだだけで動くと判断せず、Copilot に Web サイトを起動してもらい、Codespaces で転送したブラウザーから更新された UI を確認します。

1. Copilot に次のプロンプトを送り、アプリを起動してもらいます。

   ```plaintext
   ブラウザーで星評価の変更を確認できるように、アプリを起動してください。URL を教えて、サーバーは実行したままにしてください。
   ```

2. Codespaces でポート `4321` が利用可能と表示されたら、**Open in Browser** を選択します。
3. ゲームカードに5段階の評価が表示されることを確認します。
4. Copilot に戻り、起動したサーバーを停止するよう依頼します。

   ```plaintext
   起動した開発サーバーを停止してください。
   ```

## 最初のプルリクエストを作成してマージする

機能を作成できました。次はプルリクエスト (PR) を作成し、新しいコードをプロジェクトにマージします。

1. 既定のエージェントに、次のプロンプトで変更をコミットするよう依頼します。

   ```plaintext
   レビュー済みの星評価の変更を、適切なコミットメッセージでコミットしてください。
   ```

2. `/pr create` を実行します。Copilot CLI は PR の作成時に既存のコミットをプッシュし、PR の URL を表示します。
3. Copilot CLI が表示した URL を選択するときは、<kbd>Command</kbd> (Mac) または <kbd>Ctrl</kbd> (Windows/Linux) を押しながら選択して PR を開きます。
4. 変更されたファイルとチェックを確認します。
5. 問題がなければ **Merge pull request** を選択し、マージを確定します。
6. Codespace に戻り、`/exit` で Copilot CLI を終了します。
7. ローカルの `main` を更新します。

   ```bash
   git checkout main
   git pull
   ```
