Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante situaciones realistas, una aplicación completa y una lista de trabajo compartida. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de cambios y gestionar el trabajo con agentes.

## Situación

Eres un nuevo desarrollador en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con una temática para desarrolladores. La lista de trabajo de tu equipo ya está registrada como incidencias de GitHub, listas para que las abordes. Incluye tareas de funcionalidades, como filtros y paginación, además de mejoras de calidad, como la accesibilidad y los estándares de código.

## Elige tu entorno

GitHub Copilot te acompaña dondequiera que trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller comienza con su propia configuración y utiliza la situación compartida de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en tu terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia los modos de sesión, colabora en lienzos y gestiona incidencias y solicitudes de cambios de GitHub desde la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las solicitudes de cambios que abra.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
